# 🐟 Fishlands · 大白饭之岛（网页版）

**▶ 在线游玩：<https://luminass343.github.io/fishlands-web/>**

Stacklands 式卡牌家园增量游戏。网页单文件、零依赖、点开即玩，进度自动保存在浏览器里。

## 玩法循环
1. **钓鱼**：DeepSeek 自动钓，或按住左下角钓鱼点甩竿 → 上钩后连点。
2. **煮饭**：把大肥鱼拖到电饭锅旁 → 煮出大白饭。
3. **写书**：Claude 解锁书桌后自动写书页，也可在书桌按住往下划（4 笔=1 页）。
4. **铸币/装订**：学技能后双击电饭锅/书桌翻面。
5. **寻宝**：GLM 巡岛发现银矿，点击开采，拖进熔炼炉炼银条。
6. **升级**：Token 币拖到角色身上开技能面板。
7. 🎵 内置生成式背景音乐与全套交互音效，右下角 🎵声音 可调节。
